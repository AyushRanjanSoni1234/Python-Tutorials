# 📘 Data Science Tutorial Repository

Welcome to the **Data Science Tutorial** repository! This collection is designed for learners and professionals who want to build a strong foundation in Data Science, covering everything from **Python programming** to **advanced machine learning** and **deep learning concepts**.

---

## 🚀 What's Inside?

This repository is organised into modular folders and Jupyter notebooks that progressively cover:

### 🔹 1. Python Programming (Beginner to Advanced)
- Introduction to Python
- Variables, Data Types, and Operators
- Control Flow (if, loops)
- Functions and Modules
- File Handling
- Object-Oriented Programming (OOP)
- Exception Handling
- Python Libraries for Data Science:
  - NumPy
  - Pandas
  - Matplotlib & Seaborn
  - Scikit-learn
  - Statsmodels

### 🔹 2. Statistics & Mathematics for Data Science
- Descriptive Statistics
- Probability Theory
- Hypothesis Testing
- Linear Algebra
- Calculus Basics
- Gradient Descent Explained
- Mathematical intuition behind ML models

### 🔹 3. Machine Learning Concepts
- Supervised Learning
  - Linear Regression
  - Logistic Regression
  - Decision Trees
  - Random Forest
  - Support Vector Machines
- Unsupervised Learning
  - K-Means Clustering
  - Hierarchical Clustering
  - PCA (Dimensionality Reduction)
- Model Evaluation Techniques
  - Confusion Matrix, ROC, AUC, etc.
- Hyperparameter Tuning
- Cross-Validation

### 🔹 4. Deep Learning Concepts
- Introduction to Neural Networks
- Perceptron and Activation Functions
- Backpropagation & Optimization
- Building Deep Learning Models with:
  - TensorFlow
  - Keras
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)
- NLP Basics and Embeddings

---

## 🧠 Mathematical Explanations

Throughout the notebooks, you’ll find **step-by-step mathematical explanations** of algorithms to help you understand the "why" behind the models:
- Derivations of cost functions
- Gradients and optimization
- Regularization techniques
- Loss functions and their curves
